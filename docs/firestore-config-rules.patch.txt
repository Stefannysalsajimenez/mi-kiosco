PARCHE MANUAL PARA firestore.rules
==================================

1. Después de la función isAuthenticated(), agregue:

function isAdmin() {
  return isAuthenticated()
    && (
      request.auth.token.admin == true
      || request.auth.uid in ['REEMPLAZAR_UID_ADMIN']
    );
}

Reemplace REEMPLAZAR_UID_ADMIN por el UID real del administrador. Para varios
administradores, agregue los UID dentro de la lista. También puede usar solo el
custom claim admin == true cuando ya esté configurado.

2. Busque el bloque actual:

match /config/{documentId} {
  allow read: if true;
  allow write: if isAuthenticated();
}

Reemplácelo por:

match /config/admin {
  allow read, write: if isAdmin();
}

match /config/{documentId} {
  allow read: if documentId != 'admin';
  allow write: if documentId != 'admin' && isAuthenticated();
}

IMPORTANTE
----------

1. Los match superpuestos en Firestore se evalúan con OR. Por eso el match
   genérico debe excluir config/admin tanto para lectura como para escritura.

2. Este parche protege los tokens FCM, pero conserva la lectura pública de los
   demás documentos de configuración que utiliza la tienda.

3. El bloque actual de orders permite lectura pública. Se mantiene para que el
   seguimiento sin autenticación por nombre funcione. Esto no es privado.

4. El UID o custom claim usado aquí debe corresponder a los administradores
   autorizados también en ADMIN_UIDS del backend.

5. Antes de desplegar:

firebase emulators:start --only firestore
firebase deploy --only firestore:rules
